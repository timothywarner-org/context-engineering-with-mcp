SAY
The client can discover request_rollback, but discovery doesn't grant permission to execute it. API Management returns 403 with the tool-allowlist-denied marker. We're denying the operation at the gateway. The rollback tool is a harmless fixture that can't change a service.

Teaching point: A tool appearing in discovery does not authorize its execution.

06 / 07 · 9:42:20 - 9:43:1555 seconds

Prove throttle isolation

Screen: PowerShell, showing the runbook burst followed by the incident result.

Inspect the actual throttle boundary
# Report the observed call number; distributed counters are approximate.
$r.PSObject.Properties |
    Where-Object Name -Like 'runbook_*' |
    ForEach-Object {
        [pscustomobject]@{
            Call       = $_.Name
            HTTP       = $_.Value.status
            Route      = $_.Value.route
            RetryAfter = $_.Value.retryAfter
        }
    } | Format-Table -AutoSize

$r.incident_after_throttle | Format-List status,route
SAY
Now the runbook requests reach a 429 response, and Retry-After tells the client when to try again. The incident lookup still succeeds. You can apply a rate limit to an expensive tool while keeping incident retrieval available. The configured limit is two calls per minute, but the distributed counter is approximate, so I wouldn't promise which numbered call gets rejected.

Teaching point: Require an observed 429 + Retry-After, followed by a successful incident lookup. The captured run rejected runbook call 4; Thursday's ordinal may differ.

Inspect authentication and the forged routing hint
# Keep each boundary named so equal status codes stay distinguishable.
@(

    [pscustomobject]@{Check='Direct ACA without key'; HTTP=$r.direct_without_key.status; Route='-'}
    [pscustomobject]@{Check='Forged runbook routing hint'; HTTP=$r.spoofed_route.status; Route=$r.spoofed_route.route}
) | Format-Table -AutoSize

Point to: the two 401 results and the forged hint's 200 / incidents. In the policy, show the separate backend credential injection and removal of the caller's routing hint. Do not open secret values.

SAY
Finally, a request without the gateway key gets 401. Calling the container directly without its separate backend credential also gets 401. That container address is public; the credential protects the MCP operation. Our example uses keys. OAuth consent and user permissions need their own implementation. Keep the decisions separate as you work through the next scenario: who can connect, which tool they can call, and how often they can call it.
